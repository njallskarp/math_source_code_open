# Open mathematical research source code

Reproducible source artifacts for mathematical research contributions.

- [`ramsey_r55_cyclic43/`](ramsey_r55_cyclic43/) — exact constrained Ramsey
  multiplicity of red-to-blue perturbations of Exoo's `Cyclic(43)` coloring.
- [`qlp42_all_proper_quotients/`](qlp42_all_proper_quotients/) — primitive
  cyclotomic kernel and sharp residual-energy gap for every proper quotient
  constraint at quaternary Legendre-pair length 42.
- [`lucas_schur_b3/`](lucas_schur_b3/) — complete elementary-positive
  canonical width-three slice of the Lucas--Bergeron--Vessenes conjecture.
- [`lucas_schur_b4/`](lucas_schur_b4/) — complete Schur-positive canonical
  width-four slice via KOH recurrences and adjacent-layer pairings.
- [`lucas_schur_b5/`](lucas_schur_b5/) — unpacked source for all four
  nontrivial canonical width-five rays; the aggregate remains provisional
  pending independent review of the `(2,5)` certificate.
