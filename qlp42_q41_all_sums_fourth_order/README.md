# All four exact sums in the QLP-42 `q=41` fourth-order layer

This directory intersects the complete `q=41` fourth-order autocorrelation
classification with all four exact Gaussian sum equations. It counts axis
pairs that admit at least one compatible sign lift; it does not count those
sign lifts themselves.

## Exact classification

For a canonical sum case `(p,q,x,y)`, the required transformed sums are

```text
sum(S_A) = (p+q) + (q-p)i,    sum(H_A) = 0,
sum(S_B) = (x+y-1) + (y-x)i,  sum(H_B) = 1.
```

leaves exactly:

## Zero-direction lemma for reflected family A

Let `U_H(a)` and `U_S(a)` be the fourth-order syndrome images generated by
flipping both entries of one reflected family-`A` pair. In fact the earlier
inclusion `U_H(a),U_S(a) subset image(D_b)` sharpens to

```text
U_H(a) = U_S(a) = {0}                         for every reflected axis word a.
```

The fourth-order sign map has column `j`

```text
D_beta(e_j)_s = beta_(j+s) + beta_(j-s).
```

Reflection gives `beta_j=beta_(-j)`, hence the columns for a reflected pair
`j,-j` agree and their simultaneous-flip direction is zero. This applies to
both components because complementing an axis word does not change `D_beta`.

Exact Gaussian arithmetic also shows that all four phases of the exceptional
entry `S_A(0)=(1+i)c` have the same fourth-order residual. Consequently the
exact `H_A` and `S_A` sums only decide whether a sign assignment exists; when
one exists, the residual syndrome is unique. The family-`B` exact-sum support
then decides the match by a single membership test.

For `H_A`, sum zero is feasible exactly when the active reflected-pair count
is even on each axis. For `S_A`, subtract one of the four possible center
values `(1,1),(-1,1),(-1,-1),(1,-1)`, divide by two coordinatewise, and use
the standard signed-sum bound-and-parity criterion on the active real and
imaginary pairs.

## Scope and novelty

This is an exact finite classification inside the autocorrelation equations
modulo `(1+i)^4` plus all four global sums. It does not impose the complete
integer nonzero-shift autocorrelation equations and does not settle QLP-42.
The aggregate computation trusts the pinned predecessor implementations,
Python and C++ integer semantics, compiler/interpreter, operating system, and
hardware. The direct implementation-independent audit is sampled rather than
a second aggregate enumeration.

The result is apparently new relative to the searched primary QLP literature
and the committed Discovery Net graph, not a historical-priority claim.
