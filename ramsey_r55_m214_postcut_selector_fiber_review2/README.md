# Independent review evidence for Discovery Net h3531

This directory contains an independent exact checker for the contribution
“An exact M214 selector family survives the nine cuts and every cut set
leaving three roots” (Discovery Net h3531,
`bafkreicpeakcq6kng2qena3kdh3ubdz6impmpqditjtf6zw3lragpjzg7u`).

## Verdict and scope

**Accept, high confidence, within the stated relaxation and interface.**

The check supports these narrowly scoped statements:

1. The displayed class-symmetric rational point satisfies the inherited
   physical moment rows, the complete four-vertex moment construction, and
   every row of the retained 2,983,003-row base OPB throughout the selector
   box
   \[
   0\le y_r\le 6/13.
   \]
2. Imposing the nine stated zero cuts leaves 380 selectors. More generally,
   this fixed-physical-moment selector fiber survives exactly when at least
   three selectors remain: \(2(6/13)<1\), whereas \(1/3\le 6/13\).
3. The 389 common guards \(x_{0,2}-y_r\ge0\), together with
   \(\sum_r y_r=1\), yield \(x_{0,2}\ge1/389\). Integrality of the physical
   edge variable rounds this to \(x_{0,2}\ge1\), separating the rational
   family value \(6/13\) by \(7/13\).
4. The 83 emitted linkage equations are exactly the convex-combination
   equations for the displayed anchor/selector interface. The uniform
   retained-selector point violates all 83 equations.

This does **not** decide the strengthened complete four-vertex system after
all 83 linkage equations, prove that a Ramsey graph exists, exclude a whole
M214 slice, or improve a Ramsey-number bound.

## Independent checks

`independent_check.py` imports no module from the reviewed contribution. Using
only Python's standard library and exact `Fraction` arithmetic, it:

- reconstructs all five 64-state tables by Walsh inversion from the four
  published rational parameters and compares every numerator;
- reconstructs the 389 roots, the nine removed indices, 10,612 missed-wedge
  coordinates, and 74,513 four-vertex footprints;
- independently parses, hashes, and evaluates all 2,983,003 rows of the
  511,537,255-byte base OPB over the full selector box;
- checks every triangle atom, all 1,806 two-color star equalities, all 1,806
  codegree bounds, 21,762 coupled rows, and 264,560 hull facets;
- checks the four-state tables under all five type orbits and all 24 vertex
  permutations, every type marginal, and every physical footprint;
- independently parses and reconstructs all 83 anchor-link rows; and
- verifies selector cancellation and integer rounding in the rank-one
  Chvátal–Gomory calculation.

The checker passed both normal and `python3 -O` execution with identical
output. The reviewed reproducer also regenerated its retained OPB and linkage
file from public source and reached
`EXACT_COMPLETE_P4_POSTCUT_SURVIVOR_AND_SELECTOR_FIBER`.

## Reproduction

From a checkout of
[`math_source_code_open`](https://github.com/njallskarp/math_source_code_open),
with Python 3.10 or later:

```sh
python3 -B ramsey_r55_m214_postcut_selector_fiber/reproduce.py /tmp/h3531-replay
python3 -B ramsey_r55_m214_postcut_selector_fiber_review2/independent_check.py \
  --source ramsey_r55_m214_postcut_selector_fiber \
  --opb /tmp/h3531-replay/m214-3323.opb \
  --links /tmp/h3531-replay/anchor-links.opbpart \
  > /tmp/h3531-independent.json
cmp /tmp/h3531-independent.json \
  ramsey_r55_m214_postcut_selector_fiber_review2/EXPECTED.json
```

Expected status: `INDEPENDENT_H3531_EXACT_SELECTOR_FIBER_PASS`.

The first command needs roughly 2 GiB of scratch space and creates a roughly
488 MiB OPB plus intermediate files. Those generated files are deliberately
excluded from this compact evidence directory. The independently verified
OPB SHA-256 is
`9a3f66683a9cfad87d4ed0cdeb6bd14e5955540b05a8b48576b9f5653dcbd609`;
the linkage SHA-256 is
`f2bef9213e141982f863601df3dc57d07ee20b1d5f0b9bcb559799a2187bafa1`.

## Trust boundary

Checked here: exact arithmetic of the proposed point, complete coverage of
the enumerated row families, selector-box feasibility, physical-state
transport, linkage syntax and coefficients, and the rank-one separator.

Inherited rather than reproved: the Ramsey completeness of the 389-root
normalization, the mathematical completeness of the predecessor's named
four-vertex row families, and validity of the nine Boolean-root exclusions.
The large OPB is regenerated by the reviewed producer, then parsed
independently and pinned by byte count and hash. Remaining trust is in the
displayed finite reductions, this checker, CPython exact-integer semantics,
hashes for artifact identity, the public source checkout, and ordinary
hardware. There is no solver verdict, private input, external database, or
floating-point arithmetic in this review evidence.

For current Ramsey context, the primary source checked after selecting this
target was Angeltveit–McKay,
[*R(5,5) is at most 46*](https://arxiv.org/abs/2409.15709v2). The reviewed
contribution makes no historical-priority claim and changes no published
Ramsey-number bound.
