# Exact `S_B` syndrome supports in the QLP-42 `q=41` branch

This directory gives an exhaustive support classification for the six exact
Gaussian sums of `S_B` that survive the earlier axis analysis of the
length-42 quaternary Legendre-pair problem.

## Setup

Let `b in F_2^21` be the axis word of `H_B`, with a one denoting an imaginary
axis. The axis word of `S_B` is its complement, so positions with `b_j=1`
are real in `S_B` and positions with `b_j=0` are imaginary. For a sign word
`sigma in F_2^21`, define

```text
D_b(sigma)_s = sum_j (sigma_j + sigma_(j+s))(b_j + b_(j+s)) in F_2,
1 <= s <= 10.
```

Complementing the axis word does not change this map. For an exact target
`(X,Y)`, let `T_b(X,Y)` be the set of syndromes `D_b(sigma)` for sign words
whose `S_B` sum is `X+iY`. The six target cases are

```text
case 0: ( 4,-5)    case 1: ( 4,-3)    case 2: ( 0,-5)
case 3: ( 4,-1)    case 4: ( 4, 1)    case 5: ( 0,-3).
```

The preceding exact-`H` analysis forces `wt(b)=0 mod 4`, leaving 523,776
labeled words in 24,946 cyclic-rotation orbits.

## Structural results

For every such `b` and every one of the six targets,

```text
T_b(X,Y) subset {t in image(D_b) : parity(t)=0}.            (1)
```

Indeed, the sum of the ten syndrome coordinates equals `b dot sigma`.
Here `b dot sigma` is the parity of the negative real entries of `S_B`,
namely `(wt(b)-X)/2`; it is even because `wt(b)=0 mod 4` and `X` is zero or
four. For nonzero `b`, the right side of (1) has `2^(rank(D_b)-1)` elements.

There is also an exact target symmetry

```text
T_b(4,-1) = T_b(4,1).                                      (2)
```

Adding the indicator of the imaginary `S_B` positions to `sigma` flips the
sign of the imaginary component while leaving the real component fixed.
That indicator lies in the kernel of `D_b`, proving (2). The exhaustive
program checks (1) and (2) syndrome by syndrome.

## Certificate and reproduction

The C++20 verifier enumerates one canonical member of every cyclic orbit,
constructs `D_b` and its image, and obtains every exact fixed-cardinality
fiber through integer Krawtchouk coefficients followed by a 1,024-point
Walsh transform. No floating point is used.

```sh
SDK_CPP="$(xcrun --show-sdk-path)/usr/include/c++/v1"
clang++ -std=c++20 -O3 -Wall -Wextra -pedantic -isystem "$SDK_CPP" \
  classify_s_b_syndromes.cpp -o classify_s_b_syndromes
./classify_s_b_syndromes
./classify_s_b_syndromes --table | shasum -a 256
./classify_s_b_syndromes --stream | shasum -a 256
./classify_s_b_syndromes --sample-stream | shasum -a 256
python3 independent_sample_check.py
shasum -a 256 -c SHA256SUMS
```

The complete canonical support stream has SHA-256

```text
1e0d2790039844e52c0fb93fd008b6420d7476691676552c5140da22bc90696b
```

The independent Python checker does not use Krawtchouk coefficients or a
Walsh transform. It reconstructs 3,096 target supports on 516 deterministic
axis orbits using fixed-cardinality subset-XOR sets. The sample covers every
realized rank `0,3,4,6,7,9,10` and exactly matches the primary sample-stream
digest

```text
12124e91beecd8b4607b9bd54d080318b7b41c1212532fa3cbb8d6633b8bc2f2.
```

Tested with Apple clang 17.0.0 and Python 3.12.12 on arm64 macOS 26.2.

## Scope and trust boundary

This is an exact finite classification of the `S_B` syndrome supports for
the six global-sum cases and every `b` allowed by the preceding exact-`H`
condition. It does not yet intersect these supports with the fourth-order
residuals for family `A`, impose the exact `S_A` sum, or settle QLP-42.
The aggregate result trusts the C++ compiler, integer arithmetic, exhaustive
orbit enumeration, operating system, and hardware. The independent audit
checks all ranks but is sampled rather than a second exhaustive aggregate
implementation. No historical-priority claim is made.
