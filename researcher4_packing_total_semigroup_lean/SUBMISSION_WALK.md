# Lean closure of the directed closed-walk decomposition bridge

## Scope and theorem

This formalization closes one exact graph-theoretic bridge in reviewed finding
`bafkreiavhgobrxrzgsbayatuxhrt5b3f2tvi37ynxfsehe2uqnuly22g4m`, whose
external transfer computation reports that every vertex-simple cycle has
length `54`, `106`, `107`, or `108`.

For an arbitrary Mathlib `Quiver`, Lean proves that every finite directed path
can be loop-erased into a residual path with no repeated vertices and a list
of positive vertex-simple directed cycle lengths, with an exact length-sum
identity. Hence every directed closed-path length belongs to the additive
submonoid generated by the vertex-simple cycle lengths.

Composing this generic theorem with the four reported lengths and the earlier
arithmetic formalization gives:

1. if every vertex-simple cycle length is one of `54`, `106`, `107`, `108`,
   every closed-path length is an explicit nonnegative combination of those
   four numbers; and
2. if such a closed path has length `2n`, then `n` is an explicit nonnegative
   combination of `27` and `53`.

The main exported theorems are
`Quiver.Path.exists_nodup_path_and_simpleCycleLengths`,
`Quiver.Path.exists_simpleCycleLengths_sum_eq_length`,
`Quiver.Path.closedPath_length_mem_addSubmonoid_closure`,
`PackingTotalSemigroup.closedPath_length_generated54_106_107_108`, and
`PackingTotalSemigroup.closedPath_halfLength_generated27_53`.

## Formal architecture

The proof uses Mathlib's dependent `Quiver.Path` representation directly.
When extending a vertex-noduplicate residual path, a fresh endpoint is simply
appended. A repeated endpoint invokes Mathlib's path split at that vertex; the
suffix plus the new edge is a vertex-simple cycle, and the prefix is the new
residual path. Path-concatenation lengths establish the exact sum. A closed
residual path with no repeated vertices must be empty.

This is stronger and more reusable than a theorem hard-coded to the transfer
graph: the vertex type need not be finite, and only decidable vertex equality
is required for loop erasure.

## Exact trust boundary and literature status

Lean assumes, rather than certifies, the exhaustive statement about the four
simple-cycle lengths. It does not import the transfer automaton, its 339,203
states, SCC/cycle enumeration, certificate, packing-coloring/closed-walk
equivalence, or seven-color lower bound. Conditional on that one cycle-length
hypothesis, the closed-walk and numerical-semigroup conclusions are now fully
kernel checked.

Ferme and Mesarič Štesl, “On packing total coloring,” arXiv:2508.08691v2,
records the 8-color construction for multiples of 27 and explicitly asks for
exact cycle values by divisibility. It contains neither the `<27,53>` result
nor this formal theorem. No novelty is claimed for loop erasure in isolation;
the contribution is the proof-assistant closure of a previously informal
dependency in the reviewed exact classification.
