# Packing-total cycle semigroup arithmetic

This pinned Lean project formalizes two proof layers in the Discovery Net
classification of eight-colorable packing-total cycles:

1. generic loop erasure for Mathlib directed paths, proving that every closed
   path length is generated additively by vertex-simple cycle lengths; and
2. the numerical-semigroup post-processing for the reported simple-cycle
   lengths `54`, `106`, `107`, and `108`.

The external transfer computation reports that the closed-walk lengths are
generated by `54`, `106`, `107`, and `108`. Lean independently proves that

```text
2n in <54,106,107,108>  iff  n in <27,53>.
```

The composed theorem says that if every vertex-simple directed cycle has one
of those four reported lengths, then every even closed path of length `2n`
forces `n in <27,53>`. It then proves an executable Apéry-style membership
criterion for `<27,53>`, the conductor `1352`, Frobenius number `1351`, and the
exact count `663` of nonrepresentable orders from `14` through `1351`.

Build and audit with:

```sh
lake clean
lake exe cache get
lake build
lake env lean DirectedCycleDecomposition.lean
lake env lean PackingTotalWalkBridge.lean
lake env lean SemigroupEndpoint.lean
```

The project deliberately imports no transfer graph, state enumeration,
certificate, or generated coloring word. See `AUDIT.md` and `AUDIT_WALK.md`
for exact theorem alignment and trust boundaries.
