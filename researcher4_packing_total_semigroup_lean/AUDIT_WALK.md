## Exact informal and Lean theorems

For an arbitrary quiver and any finite directed path, repeated vertices can be
erased one loop at a time. The residual path has no repeated vertices, every
erased loop is a positive vertex-simple directed cycle, and lengths add
exactly. Consequently:

> The length of every directed closed path belongs to the additive submonoid
> generated by the lengths of its quiver's vertex-simple directed cycles.

The formalization uses Mathlib's dependent `Quiver.Path` directly. A path
`p : Path v v` is vertex-simple when `0 < p.length` and
`p.vertices.dropLast.Nodup`; dropping the final vertex permits the required
return to `v` while forbidding every other repetition.

Exported generic results in `DirectedCycleDecomposition.lean` are:

- `Quiver.Path.IsVertexSimpleCycle`;
- `Quiver.Path.IsVertexSimpleCycleLength`;
- `Quiver.Path.exists_nodup_path_and_simpleCycleLengths`;
- `Quiver.Path.length_eq_zero_of_closed_vertices_nodup`;
- `Quiver.Path.exists_simpleCycleLengths_sum_eq_length`; and
- `Quiver.Path.closedPath_length_mem_addSubmonoid_closure`.

The last theorem states, with no finiteness assumption on the vertex type,
that if a set `S` contains every vertex-simple cycle length, then every closed
path length lies in `AddSubmonoid.closure S`. The constructive decomposition
requires only `DecidableEq V`, as supplied by any concrete finite transfer
state.

`PackingTotalWalkBridge.lean` composes this generic theorem with the existing
arithmetic module. Its main theorems are:

- `closedPath_length_generated54_106_107_108`: if every vertex-simple cycle
  length is one of `54`, `106`, `107`, `108`, every closed-path length is an
  explicit nonnegative combination of those four numbers; and
- `closedPath_halfLength_generated27_53`: if additionally the closed path has
  length `2*n`, then `n` is an explicit nonnegative combination of `27` and
  `53`.

The quantifiers and bridge hypothesis match the computational finding: the
cycle enumeration remains a hypothesis, while the previously informal
closed-walk and semigroup implications are kernel checked.

## Proof architecture

Induct on a directed path while maintaining a vertex-noduplicate residual
path and a list of erased simple-cycle lengths. When a new terminal vertex is
fresh, append it to the residual path. When it already occurs, Mathlib's
`exists_eq_comp_of_mem_vertices` splits the residual path at that vertex. The
suffix followed by the new edge is a vertex-simple cycle, and the prefix is
the new residual path. `Quiver.Path.length_comp` gives the exact additive
length identity.

For a closed path, a vertex-noduplicate residual path must be empty: any
positive path from `v` back to `v` repeats `v`. Induction over the resulting
cycle-length list proves membership in `AddSubmonoid.closure`. A second list
induction combines explicit four-generator witnesses, and the earlier parity
theorem converts an even four-generator length into membership in `<27,53>`.

## Trust boundary and literature status

Lean does not import or verify the transfer automaton, reachability, its
339,203 states and 437,094 edges, SCC computation, the 424-state recurrent
core, exhaustive enumeration of 640 simple cycles, or the claim that their
only lengths are `54`, `106`, `107`, and `108`. It also does not formalize the
packing-coloring/closed-walk equivalence or the seven-color lower bound.

The primary paper is Ferme and Mesarič Štesl, “On packing total coloring,”
arXiv:2508.08691v2. Its current version introduces packing total coloring,
proves `7 <= chi''_rho(C_n) <= 11` for `n>=14`, records the 8-color pattern for
multiples of 27, and explicitly asks for exact cycle values with respect to
divisibility. It does not state the `<27,53>` classification or this directed
loop-erasure theorem. No novelty is claimed for the standard graph-theoretic
decomposition itself; the durable addition is its reusable Lean formulation
and exact composition with the independently formalized arithmetic layer.
